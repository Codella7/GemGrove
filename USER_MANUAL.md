# GemGrove User Manual

GemGrove helps you record gemstone purchases and sales, track payments, review customer or seller history, and receive payment reminders.

## 1. Open GemGrove

1. Open the GemGrove link in your browser.
2. Select **Register** if you do not have an account.
3. Enter your username, email address, password, and confirmation password.
4. Select **Register**.
5. Use **Log in** when you return to the app.

Passwords must contain at least 8 characters. You can log in with either your username or email address.

## 2. Main Navigation

- **Overview**: Shows totals, recent entries, and payments due soon.
- **Ledger**: Shows all purchases and sales.
- **Hajiyars**: Shows customer and seller records and their history.
- **Reminders**: Shows unpaid payments, including overdue payments.
- **Reports**: Shows a summary of entries, paid entries, carats, and total value.
- **Log out**: Signs out of your account.

The **Inventory** link, if shown in an older version, opens the Ledger.

## 3. Add a Transaction

1. Open **Overview** or **Ledger**.
2. Select **Add entry**.
3. Choose the transaction type:
   - **Sale**: A customer buys from you.
   - **Purchase**: You buy from a seller.
4. Enter the customer or seller name.
5. Choose the gemstone.
6. Choose the place.
7. Choose a currency when the selected place offers more than one.
8. Enter the number of pieces.
9. Enter the carat value.
10. Enter the price per carat.
11. Review the **Total amount**.
12. Add an image if needed.
13. Enter the transaction date.
14. Optionally enter a payment due date and notes.
15. Select **Save entry**.

### Total Amount

For a new entry, GemGrove initially calculates:

`Total amount = Carat x Price per carat`

The **Total amount** field is editable. You can change it if the final negotiated amount is different. The value saved in this field is the amount used in the Ledger, Reports, customer history, and reminders.

The **Pieces** value is recorded separately. It is not multiplied into the total calculation. The carat field should represent the carat value used for the transaction total.

## 4. Edit a Transaction

1. Open **Ledger**.
2. Find the entry.
3. Select **Edit**.
4. Change any required information.
5. Change **Total amount** directly if the negotiated amount has changed.
6. Select **Save changes**.

When editing an existing entry, the saved total is displayed. It will not be replaced unless you change it.

## 5. Search and Filter the Ledger

The Ledger can be filtered by:

- Customer, seller, or product name
- Place
- Purchase or sale
- Due or paid status
- Date from
- Date to

Select **Filter** to apply the selected filters. Select **Clear** to show all entries again.

## 6. Mark a Payment as Paid

1. Open **Ledger** or **Reminders**.
2. Find the unpaid entry.
3. Select **Mark paid**.

The entry status changes to **Paid** and it will no longer be treated as an unpaid reminder.

## 7. Delete a Transaction

1. Open **Ledger** or **Reminders**.
2. Find the entry.
3. Select **Delete**.
4. Confirm the deletion.

Deleted entries cannot be recovered through the app. Check the entry carefully before confirming.

## 8. Customers and Sellers

1. Open **Hajiyars**.
2. Select a customer or seller.
3. Review their transaction history.

The history can show:

- Number of entries
- Total carats
- Outstanding amount
- Total value
- Individual purchases and sales
- Payment status

A person is matched by name. Use consistent spelling when recording the same customer or seller.

## 9. Reminders

Open **Reminders** to see unpaid entries ordered by due date.

- **Due today** means the payment is due today.
- **Due date** shows a future payment date.
- **Overdue** means the due date has passed and the entry is still unpaid.

### Push Notifications

To receive notifications on a device:

1. Open **Reminders**.
2. Select **Enable notifications**.
3. Allow notifications in the browser.
4. Keep notifications enabled for the browser or installed app.

Push reminders work per device. Each phone or browser must be enabled separately.

For an unpaid payment:

- A payment due today can generate a due-today notification.
- An unpaid overdue payment can generate an overdue notification each day.
- Running the reminder service more than once on the same day does not send duplicate notifications to the same device.
- Marking the payment as **Paid** stops future reminders.

## 10. Install GemGrove on a Device

### Chrome or Edge on Desktop

1. Open GemGrove using the secure HTTPS link.
2. Log in.
3. Select **Install app** in the top navigation when it appears, or use the install icon in the browser address bar.
4. Confirm the installation.

### Android

1. Open GemGrove in Chrome using the HTTPS link.
2. Open the browser menu.
3. Select **Install app** or **Add to Home screen**.
4. Confirm.

### iPhone or iPad

1. Open GemGrove in Safari using the HTTPS link.
2. Select the **Share** button.
3. Select **Add to Home Screen**.
4. Select **Add**.
5. Open GemGrove from the new home-screen icon.
6. Open **Reminders** and enable notifications.

The app still needs an active server and internet connection for creating, editing, and saving entries. Installation does not make the entire app available offline.

## 11. Reports

Open **Reports** to review:

- Total entries
- Paid entries
- Total carats
- Total value by currency

Reports use the saved **Total amount** for each entry, including any negotiated total entered manually.

## 12. Images and Notes

When creating or editing a transaction, you can upload a JPEG, PNG, or WebP image up to 5 MB.

A new image replaces the previous image. When editing an entry, select **Remove current image** if you want to delete the existing image without uploading a replacement.

Use Notes for delivery details, contact information, negotiation details, or other reminders.

## 13. Privacy and Account Safety

- Do not share your password.
- Log out when using a shared computer.
- Use the HTTPS GemGrove link.
- Review names, amounts, dates, and currency before saving.
- Treat uploaded images and transaction information as private business data.

## 14. Troubleshooting

### I cannot see the Install app button

The button is normally shown only when the browser confirms that the site can be installed. Use the browser install menu instead. Make sure you are using HTTPS and are not in a private or incognito window.

### I do not receive notifications

Check that:

1. You enabled notifications on the Reminders page.
2. The browser has notification permission.
3. Notifications are not blocked in device settings.
4. The device is connected to the internet.
5. You enabled notifications on the current device or browser.

### A payment still appears as overdue

Open the entry and select **Mark paid**. Editing the total amount alone does not change the payment status.

### I entered the wrong amount

Open the entry, select **Edit**, correct the **Total amount**, and select **Save changes**.

### I cannot save a transaction

Check that all required fields are completed, including transaction type, customer or seller, gemstone, place, pieces, carat, price per carat, total amount, currency, and transaction date.

## 15. Important Reminder

GemGrove records the information you enter. Always review the transaction before saving, especially the negotiated total, currency, due date, and payment status.
